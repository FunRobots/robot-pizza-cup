# Media Generation Specification

## Creative Direction

**Core visual concept:** a small, real, accessible robot arm learning a familiar human task. Avoid
futuristic humanoid clichés.

The event should feel: experimental; technical; playful; credible; open-source; hands-on.

## Visual Motifs

Use combinations of: SO-101 arm; pizza; red pepperoni tokens; dataset/video frames; trajectories;
terminal/training screen; leaderboard; people teleoperating robots.

## Important Authenticity Rule

Generated promotional imagery should resemble the actual competition. **Do not depict:** humanoid
robots; industrial six-axis robots (SO-101 is the actual platform); robot hands kneading dough;
autonomous ovens; capabilities absent from the event.

Marketing should slightly dramatize the event, not misrepresent it.

## Asset 1 — Hero Image

**Purpose:** landing page, announcement, sponsor deck.

**Composition**
- Foreground: SO-101 arm; gripper holding pepperoni; pizza directly underneath.
- Background: hackathon environment; participants; laptops; subtle robotics screens.

**Versions:** 1920 × 1080; 1600 × 900; 1080 × 1350; 1080 × 1080.

**Leave negative space** reserved for the wordmark: ROBOTICS / PIZZA / HACKATHON.

## Asset 2 — Technical Hero

Show the pipeline visually:

```
Human teleoperation
      ↓
Dataset frames
      ↓
Model training
      ↓
Autonomous robot
      ↓
Pizza
```

Purpose: technical communities and sponsors.

## Asset 3 — Challenge Cards

One visual per challenge.

- **Precision Topping** — robot placing pepperoni on targets.
- **Recipe Assembly** — two ingredient bins + recipe text.
- **Mystery Pizza** — changed positions / question mark / competition clock.

**Formats:** 16:9; 1:1; 4:5.

## Asset 4 — Announcement Video

**Duration:** 15–20 seconds. **Format:** primary 9:16, secondary 16:9.

**Storyboard**

| Time | Content |
|---|---|
| 0–2s | Robot holding pepperoni. Text: CAN YOU TEACH A ROBOT TO MAKE PIZZA? |
| 2–5s | Human teleoperates robot. DEMONSTRATE |
| 5–8s | Dataset/training visuals. TRAIN |
| 8–11s | Autonomous robot moves. DEPLOY |
| 11–14s | Robot places topping. COMPETE |
| 14–18s | Event branding. 48 HOURS · OCT 30 – NOV 1 · APPLY NOW |

## Asset 5 — Challenge Explainers

Three videos, 15–30 seconds each.

**Structure:** Challenge → Task → What AI capability it tests → Points.

## Asset 6 — Technical Explainer

**Duration:** 30–60 seconds. **Audience:** ML/robotics engineers.

**Explain:** Teleoperation → LeRobot dataset → SmolVLA → physical deployment → hidden evaluation.

This is important because spectacle attracts attention but technical credibility attracts strong
participants.

## Asset 7 — Real Prototype Video

This is the single most valuable pre-event marketing asset.

**Capture:** human teleoperating SO-101; dataset recording; training command/dashboard; autonomous
robot attempting placement; successful placement; failed placement.

Use actual footage. Even an imperfect working prototype is more persuasive to technical participants
and sponsors than polished AI-generated imagery.

## Asset 8 — Failure Reel

Robotics failures are inherently engaging.

**Capture:** missed grasp; dropped pepperoni; near-perfect placement; robot stopping; improvement
after retraining.

**Possible message:** *"Day 0: 0/6. 50 demonstrations later: 5/6."* Only use real measured claims.

## Asset 9 — Event Graphics

Reusable templates for: team introduction; leaderboard; challenge score; finalist card; winner
announcement; sponsor thank-you; quote; daily recap.

## Asset 10 — Livestream Package

Prepare: 16:9 title card; lower thirds; team name overlay; current score; challenge name; timer;
sponsor rotation; standby screen.

## Media Capture List During Event

**For every team, capture:** wide team shot; teleoperation; laptop/model work; robot close-up;
autonomous run; reaction; 10-second participant quote.

**For winners, capture:** complete evaluation run; model explanation; team celebration; pizza shot.

## Shot Priority

If media resources are limited:

1. Robot action close-up
2. Human + robot interaction
3. Success/failure reaction
4. Training/data screen
5. General atmosphere

Robotics footage should visually prove that the robot is operating autonomously during evaluation.

## Generative Media Workflow

**Before physical prototype exists:** use generated imagery for moodboard, announcement concept,
challenge diagrams, visual identity.

**After prototype works:** transition campaign toward real footage.

**Recommended progression**

```
Concept art
    ↓
Real prototype
    ↓
Real participant/team content
    ↓
Live competition
```

By event week, the majority of technical promotional content should use the actual platform.

## Final Marketing Narrative

**Do not frame the story as:** *"We built a robot that makes pizza."*

**Frame it as:** *"We gave teams 48 hours, real robot hardware and a Physical AI stack. Then we gave
their models a pizza challenge they hadn't seen before."*

That narrative can scale beyond the first event. The robot is the medium. The competition is the
product.
